# Отчёт о проходе доступность / производительность / страницы культур / SEO

`CENTRAGRO-report-2026-08-07.pdf` — отчёт владельцу на 9 страницах: таблица
метрик до/после, попиксельное сравнение по фазам, фрагменты единственного
намеренного визуального изменения (контраст), доказательства того, что страница
культуры оформлена тремя вариациями по-разному, перечень новых CSS-классов,
что не сделано и почему, и что требует решения владельца.

`build_pdf.py` пересобирает его из данных замеров через печатный движок Chromium
(LaTeX в контейнере нет, а Chromium уже стоит для харнесса скриншотов):

    python3 docs/report/build_pdf.py

Скрипту нужны `metrics.json` и три PNG рядом с ним — они лежат в `.qa/`, которая
не коммитится. Отчёт здесь как готовый артефакт; пересборка нужна только если
замеры повторят.
