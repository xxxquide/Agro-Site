# Отчёт о проходе: доступность, время блокировки, страницы культур, SEO

## Что читать

**`REPORT.md`** — сам отчёт. Таблица метрик до/после, попиксельное сравнение по
фазам, единственное намеренное визуальное изменение, перечень новых CSS-классов,
что не сделано и почему, что требует решения владельца, побочные находки.
GitHub рендерит его прямо в браузере.

## PDF

Тот же отчёт с иллюстрациями — фрагменты контраста до/после, страница культуры
в трёх вариациях, пары «статья / культура» — свёрстан на 9 страниц A4.

Он лежит здесь в base64, потому что заливался через GitHub API, а тот принимает
только текст. Восстановить:

    base64 -d CENTRAGRO-report-2026-08-07.pdf.base64 > CENTRAGRO-report-2026-08-07.pdf

Либо пересобрать из данных замеров печатным движком Chromium (LaTeX в контейнере
не было, а Chromium уже стоял для харнесса скриншотов):

    python3 docs/report/build_pdf.py

Пересборке нужны `metrics.json` (лежит рядом) и три PNG из `.qa/`, которая не
коммитится: `contrast-before-after.png`, `crop-three-variations.png`,
`article-vs-crop.png`. Без них скрипт упадёт на картинках — base64 выше
самодостаточен и не зависит от них.

`make_md.py` собирает `REPORT.md` из тех же структур данных, что и PDF: два
формата, один источник. Расхождение между ними было бы хуже, чем один формат.

## Если base64 в репозитории не нужен

Удалите `CENTRAGRO-report-2026-08-07.pdf.base64` — `REPORT.md` останется полным
текстом отчёта, а PDF всегда пересобирается скриптом.
